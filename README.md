# 🎮 3D Zombie Runner – Military Base Theme

## 📌 Project Overview

**3D Zombie Runner – Military Base Theme** is a 3D endless survival runner game developed using Unity. The game takes place in an abandoned military base affected by a zombie outbreak.

The player's objective is to survive as long as possible by avoiding obstacles, collecting coins and ammunition, and using power-ups while navigating through the dangerous military environment.

This project was developed as part of an academic project under the guidance and mentorship of **Dr. Vijaya Chandra Jadala**.

## 🎯 Objectives

- Develop an engaging 3D endless runner game.
- Design an immersive military base environment.
- Implement zombie survival gameplay mechanics.
- Create interactive obstacles and collectible items.
- Improve practical skills in Unity game development and C# programming.

## ✨ Key Features

- **3D Endless Runner:** Continuous running and survival gameplay.
- **Military Base Environment:** Abandoned military-themed surroundings.
- **Zombie Survival Theme:** Survival experience in a zombie-infected environment.
- **Coin Collection:** Collect coins during gameplay.
- **Ammo Collection:** Collect ammunition throughout the game.
- **Obstacles and Challenges:** Avoid barriers and other environmental obstacles.
- **Power-ups:** Shield and speed boost features.
- **Score System:** Track player performance and distance.
- **Main Menu:** Dedicated game start interface.
- **Game Over System:** Displays the end of the player's run.

## 🎮 Gameplay

The player must:
1. Navigate through the military base.
2. Avoid obstacles and dangerous objects.
3. Collect coins and ammunition.
4. Use available power-ups strategically.
5. Survive as long as possible and achieve a high score.

## 🖥️ Development Environment

- Game Engine: Unity 6
- Programming Language: C#
- Platform: PC
- Project Type: 3D Endless Runner / Survival Game

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Extract the project files if downloaded as a ZIP.
3. Open Unity Hub.
4. Click **Add Project** and select the extracted project folder.
5. Open the project using a compatible Unity Editor version.
6. Open the Main Menu scene.
7. Press the Play button to start the game.
